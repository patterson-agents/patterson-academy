## Learn Claude Code the way your team will use it

Claude Code reads your codebase, edits files, runs commands and verifies its own work. That
is a different tool from an autocomplete, and it rewards a different set of habits. This
course teaches those habits: what Claude can see, how to steer it, and how to configure it
once so the whole team gets the same behavior.

Every lesson is grounded in the official Claude Code documentation, and every claim links
back to its source. Work through it in order, or use the sidebar to go straight to the
thing you need today.

## Where to start

If you have never opened Claude Code, begin at
[Getting started](/curriculum/getting-started/). If you have used it and want it configured
properly, go to [The .claude directory](/curriculum/the-claude-directory/). If you are
setting a team up this week, work the [lab](/lab/set-up-a-working-session/) end to end and
keep the [reference index](/reference/) open beside it.
