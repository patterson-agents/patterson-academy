Learn Claude Code

Six modules on the agentic loop, sessions and context, the .claude directory, the extension layer, plugin distribution and the wider ecosystem — built on the official Claude Code documentation.

Audience

Mixed beginner to advanced. Modules 1–2 assume only command-line familiarity; Modules 3–4 suit developers using Claude Code daily; Modules 5–6 target engineers packaging and distributing team tooling. Lessons are recommended in order, never locked.

Method and assessment

Docs-grounded readings with knowledge checks, a simulated terminal with per-lesson practice commands, an interactive .claude explorer, a prompt-template library and a course assistant. A 27-step hands-on lab and the Module 6 capstone verify a real setup with /context, /doctor, /hooks and /mcp.
